# Wiki tag vertical slice — verification record

**Date:** 2026-09-18. **Status:** SOURCE implemented; not accepted for database or production.

## Files and behavior

- `WikiTag`, `WikiDraftTag`, `WikiRevisionTag` and EF mapping: unique slug/normalized-name; join composite keys and restrictive foreign keys (no cascading revision deletion).
- `WikiDraftValidator` enforces max 10 distinct non-empty UUIDs; article mutations validate active tags inside serializable transactions, update draft membership and snapshot membership into new revision in same publication transaction.
- Tag Admin group inherits Admin role + CSRF. PATCH/DELETE require `If-Match`; referenced tags are protected from deactivate/delete and historical references block rename/slug change. SQL deadlocks return a narrow 409 mapping via existing handler.
- Public list, detail, tag catalog and filter consult current published revision only, never draft membership; tag catalog omits entries with zero current published references (including draft-only and old-revision-only tags). Web and Flutter consume tag list/filter.
- Disposable `scripts/wiki-smoke.mjs` has publication/isolation and tag ETag/ref scenarios, but was **not** executed against a live SQL Server.

# Local fixed-angle world map verification — 2026-09-29

## Source and privacy boundary

- Rendered the user-supplied Minecraft Java `world.zip` directly; it was not copied into the web tree or extracted wholesale.
- Renderer output in `apps/web/public/maps/nova-haven/` is a 3,200×2,304 RGBA terrain PNG (911,322 bytes), a little-endian 16-bit height field (14,745,600 bytes), and a 577-byte manifest. The manifest records 1 block per color texel; bounds X −1536…1663 / Z −1152…1151; Y 46…309; saved spawn X=191, Z=−71; data version 3955; and 27,991 chunks with renderable terrain.
- No sign labels were present. The map shows only the verified saved spawn and reports zero source signs; it does not invent place names.
- The manifest excludes seed, player, inventory, entity, and account data. The original save's redistribution/license terms were not checked, so keep this preview local unless permission is established.
- No AI-generated images, external map tiles, Wynncraft artwork, labels, or textures are used.

## Implementation boundary

- The public `/map` defaults to a fixed WebGL2 camera (45° yaw, 60° elevated view), with pan, 1×–32× zoom, block picking, source-derived spawn marker, and a one-click flat-map fallback.
- Each rendered block has its own source-derived surface-color texel. For GPU limits, the heightfield mesh samples every 4 blocks; it is not a full voxel/building reconstruction and does not include Minecraft resource-pack side-face textures. At high zoom, surface color detail is per block, while geometric edges remain four-block sampled.
- Terrain image and height-field row orientation are aligned. Height exaggeration is restrained to 1.5× so tall foliage does not dominate the view.

# Demo seed verification — 2026-09-22

## Scope

Added an explicit, idempotent local demo seed command for Vietnamese editorial fixtures. The command uses the Admin REST API, so it exercises the same CSRF, cookie, ETag and publish paths as the Admin client. It refuses non-localhost API origins and does not change schema or seed any Minecraft/plugin data.

## Commands

```powershell
$env:NOVA_API_URL='http://127.0.0.1:5081'
$env:NOVA_ADMIN_EMAIL='demo-admin@local.test'
$env:NOVA_ADMIN_PASSWORD='<local development password>'
npm run seed:demo
```

The API process used SQL Server LocalDB `NovaHaven_Local`. Port `5081` was used for the seed API because the existing local preview API occupied `5080`.

## Result

- First run: created and published Vietnamese fixtures for Wiki categories/articles/tags, News, Catalog items/recipe, Knowledge location, Community guild, Reward definition and Commerce definition.
- Second run: `DEMO SEED PASS: all fixtures already existed`.
- Public verification: Wiki categories/articles, News, Catalog items/recipes, Knowledge location, Community guild, Rewards and Commerce all returned HTTP 200.
- Homepage preview showed the three published Vietnamese categories: `Khởi hành`, `Lớp nhân vật`, `Vùng đất`.
- No remote API, production database, Minecraft/plugin database or secret was touched.
